# WeKnora Lite macOS Intel build

Manual GitHub Actions build of Tencent/WeKnora v0.9.0 at commit
`f17ee8a8da901bd658a4cb25f40b5fd41adbfdd7` for macOS 15 Intel.

Only upstream public source is downloaded. No personal configuration,
credentials, Confluence material, or research project data is uploaded.

The workflow produces a command-line Lite distribution, including the web UI,
configuration templates, SQLite migrations, license notices, and SHA-256 checksum.
Artifacts are retained for 7 days. Configure models locally after installation.
